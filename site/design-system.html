Design system

Cette page n'est liée depuis aucun menu du site : elle s'atteint en saisissant son adresse. Elle charge la vraie feuille de style, donc ce qu'on y voit est ce que le site produit. Un contrôle automatisé vérifie qu'aucune classe de style.css n'y manque.

Fondations

Couleurs

Six jetons déclarés dans :root, plus un motif hachuré. Aucune autre couleur ne doit apparaître dans le site, à deux exceptions près, héritées : #4a4438 pour le texte atténué et #8f8672 pour les mentions de cadre vide.

Typographies

Trois familles, chacune avec un rôle exclusif. Les mélanger est le moyen le plus rapide de faire dérailler la charte.

Barlow Condensed 900

Titres, scores, chiffres. Toujours en capitales, interligne 0.92. C'est la voix qui crie.
Barlow Condensed 700
Boutons, navigation, résumés d'accordéon.
Archivo — le texte courant respire à 15 px, interligne 1.65. Il passe à 16 px sous 880 px.
Corps de texte, champs de formulaire.
DM Mono — les surtitres chuchotent
Surtitres, badges, dates, métadonnées. Toujours espacé et en capitales.
h1,h2,h3,h4 → Barlow Condensed 900
.btn        → Barlow Condensed 700
body        → Archivo 15px / 16px
.mono .eyebrow → DM Mono
Paliers responsive

Deux paliers seulement. Ce sont les valeurs réelles de style.css — les vérifier ici évite de tester à la mauvaise largeur.

  • 1100 px — .cols-3 et .cols-4 passent à deux colonnes.
  • 880 px — tout passe sur une colonne, le corps grimpe à 16 px, le menu devient un burger, .match-row passe à deux colonnes avec la date sur toute la largeur, les filets verticaux deviennent horizontaux.

Largeur de contrôle retenue pour les vérifications visuelles : 360 px.

@media(max-width:1100px){ … }
@media(max-width:880px){ … }
